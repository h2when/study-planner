## 📌 소개

**나의 A+ 플래너**는  
바쁜 학기 중 시험 준비, 보고서 작성, 과제 마감, 약속 일정까지  
한 번에 관리하기 위해 만든 개인 맞춤형 스터디 플래너입니다.

날짜별로  
- 시간 스케줄 관리
- 할 일 체크리스트
- 기상/취침 시간 기록
- 일일 목표 관리
- 메모 작성

이 가능하도록 구성했습니다.

---

## 🛠 주요 기능

- ✅ 날짜별 일정 관리
- ✅ 시간대별 스케줄 수정
- ✅ 할 일 체크리스트 추가/삭제
- ✅ 기상/취침 시간 기록
- ✅ 일일 목표 설정
- ✅ 진행률 확인
- ✅ JSON 백업/복원
- ✅ 브라우저 로컬 저장 지원
